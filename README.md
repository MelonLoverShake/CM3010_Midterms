# CM3010_Midterms
This contains the resource files for the UOL databases-advanced-data-techniques mid-terms.

## Descriptation:
This is a CRUD Resale Prices of HDB Flats web application done with Javascript and Node.js. It allows querying of the Resale Flats Prices, etc. A detailed explanation of how the application works can be found at "DNW midterm report.pdf".

How to run the application:
Create the Database: node create_db.js
Connect to the database, Create Cables and Populate them with CSV data: node populate_db.js
Run web app: node index.js
Url: http://127.0.0.1:8088/
